# Security

Slopculator makes no network requests, stores sheets only on the device, and runs expressions in its own interpreter.

If you find a way to break that, such as an expression that hangs or crashes the app, escapes the interpreter, or reads something it should not, please report it privately through the repository's **Security** tab (Report a vulnerability) rather than in a public issue. Include the exact input and the platform. You should hear back within a week.

The latest alpha on the `release` branch is the only supported version.
